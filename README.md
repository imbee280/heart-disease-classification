# Heart Disease Classification — End-to-End Machine Learning

Predicts whether a patient has heart disease based on clinical attributes.

## Tools Used
Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

## ML Models Compared
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Random Forest Classifier

## Process
1. Exploratory Data Analysis (correlation heatmap, crosstabs, visualizations)
2. Feature engineering and preprocessing
3. Model training and comparison
4. Hyperparameter tuning with RandomizedSearchCV
5. Evaluation: Accuracy, Precision, Recall, F1, ROC-AUC

## Dataset
Cleveland Heart Disease dataset — 303 patients, 14 features
